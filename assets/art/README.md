# Illustrations

Drop finished illustrations here; the site picks them up by file name.

- `hero.webp` — the courtyard seen through the forecourt arch (4:5).
- `door-l.webp`, `door-r.webp` — the carved doors of the gate and every corridor room.
- `lantern-1..3.webp` — hanging brass lanterns.
- `parlour.webp` — the Darbar room in the corridor.
- `niche.webp` — the maroon niche behind the end card.
- `entrance.webp` — the sunlit palace entrance behind the gate. If you replace it, update the
  door position (`ART` in `js/site.js`) so the opening leaves sit over the painted doors.
- `gate-door-l.webp`, `gate-door-r.webp` — the gate's leaves, matching the painted doors.
- `door-green-l.webp`, `door-green-r.webp` — the studded green doors in the corridor.
